# Claude Code for PMs

This is the course workspace for Product School's "Claude Code for PMs"
certification, cohort ccpm-2026.1. Everything about Rook Industries in
this workspace is a fictional teaching scenario — it's not a real company.

## Getting started

1. Paste the course setup prompt (the one-line prompt in your pre-class
   materials) into Claude Code and follow along. Claude gets the setup steps
   from setup/SETUP.md in this course. Setup makes your own copy of this
   course on GitHub and puts it on your computer, in a folder called
   claude-code-for-pms-final. Your copy on GitHub is Public. Keep it that way
   until the course ends, so your instructor can see your work.
2. In the Claude app, start a new session on the claude-code-for-pms-final
   folder and type: check my setup
3. At the end of each module, type: wrap up

## What's in here

- **00-rook** — background on Rook Industries: the company, the product,
  the team, and the release you're stepping into. Reference material for
  every module.
- **01-origin-story** through **06-sidekicks** — the six course modules,
  in order.

Each module folder has a `prompts.md` file. That's where your work goes —
at the end of each session, type wrap up, and Claude Code saves the
prompts you wrote yourself into it, updates CLAUDE.md, and saves your work
to GitHub. By the end you have a library of your own prompts to look back
on.
